# Tick to Done

Браузерная игра Incremental / Idle Clicker на Kanban-доске. Документация лежит в `docs/` и хранится локально, вне git.

## Документация

- Начинай с `docs/README.md`: там статусы Confirmed / Proposed / Deferred, текущая версия, порядок чтения и правила ведения документов.
- Правила игры и числа баланса берутся из спецификации версии (`docs/vX.Y/prototype.md`), а не из памяти. Если в документах нет ответа, игровое правило самостоятельно не выбирается: вопрос записывается как открытый, с вариантами и рекомендацией, и решается автором.
- Папки закрытых версий (сейчас `docs/v0.1/`) не редактируются, изменения идут в папку текущей версии.

## Код

- Слои `ui → app → core`. Ядро детерминировано: время в целых микросекундах, случайность только из генератора с seed. Видимые тексты берутся только из словаря `src/i18n/locales/en.ts` по ключам. Эти правила проверяют линт и тесты.
- Числа баланса лежат в `src/config/balance.ts` и совпадают со спецификацией версии; тесты ядра проверяют правила на этих числах.
- `npm run check` — типы, линт, модульные тесты, сборка; `npm run verify` — то же плюс браузерные тесты; `npm run sim` — балансовая симуляция.
